## 1. AI 生成结果异常

| 场景 | 用户看到什么 | 业务结果 |
|------|-------------|---------|
| **生成内容不完整或无法使用** | 展示已生成内容，用户可重新生成或手工编辑 | 成功保存后覆盖当前草稿；MVP 不提供旧内容回溯，保存失败须如实提示 |
| **生成耗时较长** | 进度提示，界面可继续操作 | 生成完成后草稿自动保存至本地草稿库 |
| **AI 生成服务暂时不可用** | 明确提示生成失败 | 不生成空草稿、不虚报成功；用户可稍后重试或手工撰写 |

```mermaid
flowchart TD
    A[用户触发 AI 生成物料] --> B{生成是否成功?}
    B -->|是| C[物料保存至本地草稿库]
    B -->|否| D["提示：生成失败"]
    D --> E[用户可重试或手工撰写]
    E --> A
```

> 来源：PRD §5.4.1（生成与存盘）、§5.5.3（沙箱可见执行结果）。

## 2. 平台会话异常

| 场景 | 用户看到什么 | 业务结果 |
|------|-------------|---------|
| **渠道未登录或会话失效** | 琥珀色指示灯 + `去登录 ↗` 按钮 | 该渠道的预填与指标采集不可执行，其他渠道不受影响 |
| **账号已登录但无创作者权限** | 红色指示灯，提示权限不足 | 渠道标记为不可用，用户需前往平台开通权限 |
| **尚未探测或探测超时** | 灰色指示灯，"未知 / 探测中" | 不误报为就绪，用户可点击刷新重试 |
| **需滑动拼图 / 双因素验证** | 提示需在浏览器实例中手工完成验证 | Phase 0 由用户手工处理；Phase 2 才规划认证小窗 |

```mermaid
flowchart TD
    A[用户查看渠道卡片] --> B{会话处于哪一态?}
    B -->|未知/探测中| C["灰色灯：未知"]
    B -->|需登录| D["琥珀灯 + 去登录 ↗"]
    B -->|已认证就绪| E["绿灯：可预填与采集"]
    B -->|无权限| F["红灯：权限不足"]
    C --> G[点击刷新重新探测]
```

> 来源：PRD §5.2.1 四态生命周期、§5.2.3、§六 3。

## 3. 草稿预填异常

| 场景 | 用户看到什么 | 业务结果 |
|------|-------------|---------|
| **预填执行失败** | 显示失败原因，不显示成功 | 排期状态保持"草稿就绪"，可修正后重试 |
| **渠道未就绪时点击预填** | 提示需先完成登录 | 不执行预填，不产生草稿 |
| **预填成功但页面未显示草稿** | 提供草稿直达验证链接，用户可自行核对 | 以平台后台的真实状态为准，不单方面宣称成功 |
| **用户未回填平台 URL** | 状态停留在"已推草稿箱" | 不出现"已发布"标记 |
| **用户误填非法 URL** | 提示 URL 不合法 | 状态不推进为"已发布" |

> **业务层说明**：本场景只在排期项处于"已推草稿箱"、用户主动回填平台链接时触发。
> **用户义务**：填入的是**真实已完成发布**的平台内容链接，且确属该草稿渠道。
> **系统保证（仅此三项，不得夸大）**：工作台校验 ① 链接为 `http` / `https` 格式（经 URL 解析器，非宽松正则）；
> ② 回填渠道属于该草稿的渠道集合；③ 多渠道回填完整性。
> **系统不保证**：目标页面可达、页面内容与草稿对应、账号归属正确或发布确实已发生 ——
> 「格式合法」**不等于**「发布已核实」。判定机制详见 `criterion §4` 与 `architecture/adr_002_prefill_only_human_in_the_loop.md`「保证边界」；
> 若需平台侧自动验真，须另行定义契约（含网络访问与失败语义），不在本资产内推定。

```mermaid
flowchart TD
    A[点击一键预填至草稿箱] --> B{渠道是否就绪?}
    B -->|否| C["提示：请先完成登录"]
    B -->|是| D{预填是否成功?}
    D -->|否| E["显示失败原因"]
    E --> F[状态保持草稿就绪]
    D -->|是| G["状态变为已推草稿箱"]
    G --> H[展示 前往平台草稿箱 ↗]
    H --> I[人工在平台后台确认发布]
    I --> J{是否填入合法平台 URL?}
    J -->|否| K[状态停留 已推草稿箱]
    J -->|是| M{是否所有渠道都已回填?}
    M -->|否 仅部分渠道| K
    M -->|是| L[状态变为 已发布]
```

> **全渠道条件**：单渠道草稿回填后即"已发布"；**多渠道草稿只有全部渠道都回填有效 URL 后整条才变为"已发布"**，只回填部分渠道时固定停留在"已推草稿箱"。详见 BR-021 与 `criterion §4`。

> 来源：PRD §5.3.1 发布确认闭环、§5.4.3 安全约束。

## 4. 指标与数据异常

| 场景 | 用户看到什么 | 业务结果 |
|------|-------------|---------|
| **某平台指标采集失败** | 该指标显示"暂无数据" | 不按 0 展示，不估算填充 |
| **某平台暂不支持该指标** | 显示"暂无数据" | 与"真实为零"在界面上可区分 |
| **应采集渠道未全部成功** | 汇总指标显示"暂无数据" | 不只汇总已成功渠道冒充满盘数据 |
| **平台真实返回 0** | 正常显示 `0` | 零值作为有效值参与统计 |
| **历史数据不足以覆盖对比窗口** | 环比走势显示为空 | 不编造环比结论 |
| **评论抓取无结果** | 提示暂无可分析评论 | 不使用示例评论冒充真实数据 |

```mermaid
flowchart TD
    A[刷新大盘指标] --> B{采集是否成功?}
    B -->|失败| C["显示：暂无数据"]
    B -->|成功| D{数值是否为 0?}
    D -->|是| E[正常显示 0]
    D -->|否| F[显示数值与环比走势]
    C --> G[用户知晓数据缺失]
```

> 来源：PRD §5.1.2「核心指标卡」、§5.6；实现层口径详见 `criterion §4`。

## 5. 网络异常

| 场景 | 用户看到什么 | 业务结果 |
|------|-------------|---------|
| **网络断开** | 提示网络不可用 | 已填写的物料内容不丢失，可恢复后重试 |
| **请求长时间无响应** | 显示超时提示 | 不展示为成功，用户可重新触发 |
| **知识库中枢未连通** | 相关能力明确提示不可用 | 依赖知识库的动作（排期同步、文档沉淀、需求反哺）不执行 |
| **浏览器引擎未连通** | 状态灯变红，相关能力提示不可用 | 依赖引擎的动作（会话探测、预填、指标与评论采集）不执行 |
| **能力清单中某工具不再被连接提供** | 该工具从清单中**消失**（不列出、不保留行）；未连接通过引擎状态灯表达 | 不伪造、不承诺支持；直接调用该工具仍返回不可用（PRD §5.7.1） |

```mermaid
flowchart TD
    A[用户发起依赖引擎的操作] --> B{引擎是否连通?}
    B -->|否| C["提示：能力不可用 + 状态灯变红"]
    B -->|是| D{请求是否成功?}
    D -->|是| E[正常返回结果]
    D -->|否| F["提示失败原因或超时"]
```

> 来源：PRD §5.1.1（引擎状态指示）、§5.7（配置与连通性测试）、§5.7.1（能力管理：已启用但连接未提供）。

## 6. 多人 / 多端同时操作

| 场景 | 用户看到什么 | 业务结果 |
|------|-------------|---------|
| **同一草稿被两处同时修改** | 后保存的一方收到"内容已被更新"提示 | 不静默覆盖对方已保存的内容 |
| **用户在 Injoys 表格中修改了排期** | Phase 0–2：工作台数据不变，需手工重新导入 | 以本地排期为准（单向导出/导入）；Phase 3 才支持双向同步 |
| **已发布草稿新增了未回填的渠道** | 状态回到"已推草稿箱" | 不维持假"已发布" |

> **来源**：双向同步的阶段口径 → PRD §5.3.2（Phase 3 双向同步与冲突解决）；**"已发布草稿新增未回填渠道须回退"为架构裁决的全渠道不变量 → `criterion §4`、架构文档 §3.2.5（非 PRD 明文）**。具体冲突判定机制属于架构文档，此处仅记录用户可见结果。
> **⚠️ 归属标注**：第 1 行「后保存方收到"内容已被更新"提示」是**实现层乐观锁（`criterion §3.5` 的 `version`/`expectedVersion`）派生的用户可见文案，PRD 与开发计划 §4.2 均未定义该文案**，属架构/实现层口径，业务域不新增承诺。

## 7. 界面状态文案

| 状态 | 用户看到什么 |
|------|-------------|
| **加载中** | 骨架屏或加载指示，页面其他区域可正常操作 |
| **空数据** | 明确的空状态文案（如"暂无排期"），并提供引导操作入口 |
| **出错** | 友好提示 + 失败原因，提供重试入口；不展示技术错误细节 |
| **超时** | 超时提示 + 重新触发入口 |
| **达到上限** | PRD 未涉及（使用额度**未定义**，不承诺「无限制」） |
| **指标缺失** | 显示"暂无数据"，不显示为 `0` |
| **渠道未登录** | 琥珀色指示灯 + `去登录 ↗` 外链 |

> 来源：PRD §六 3 零阻碍操作原则、§5.1.2、§5.2.1。
